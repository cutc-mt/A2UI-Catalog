A2UI で表現できる UI カタログ

A2UI（Agent to UI Protocol）は、エージェントが宣言的なJSONメッセージのストリームでUIの意図を送り、 クライアント側が自前のコンポーネントで安全に描画するためのオープン標準です。 このカタログでは、v0.9 ベーシックカタログの全18コンポーネントについて 「A2UI JSON」と「ライブプレビュー」を並べて確認できます。

  • 📦 各デモは実際のメッセージストリーム（createSurface → updateComponents → updateDataModel）をそのまま送信して描画しています
  • 🖱️ プレビューはすべて操作可能です。ボタン押下時の action イベントや、入力に伴うデータモデルの変化もその場で確認できます

⚠️ プレビューの描画には、本カタログ独自の仕様準拠ミニレンダラーを使用しています （公式レンダラー React / Lit / Angular / Flutter の見た目とは細部が異なる場合があります）。
